运行环境

凭证保留在服务端，网页只显示配置状态。

在启动服务的终端配置变量，然后重启控制台：

export LEXMOUNT_API_KEY='…'
export LEXMOUNT_PROJECT_ID='…'
export MODEL_API_KEY='…'
export MODEL_NAME='…'
export MODEL_BASE_URL='https://你的模型服务/v1'
docker pull python:3.12-slim
python -m autolex serve

也支持 LEXMOUNT_FETCH_CLI。配置检查不代表 API、网络或 Docker daemon 已连通。
